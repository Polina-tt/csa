## Опис варіанта та розмітка 32-бітного поля
Усі дані пристрою за умовою варіанта 1 мають щільно зберігатися в одній змінній типу std::uint32_t, яка займає в пам'яті 4 байти.

Схема розміщення бітів (від 31 до 0):
Біти:   | 31  28 | 27 | 26     20 | 19      12 |  11 |  10 | 9    7 | 6      0 |
Поля:   | Резерв | Серв | Температ. | Код помилки| BT  | WiFi| Режим  | Батарея  |
Ширина: | 4 біти | 1 біт|  7 бітів  |  8 бітів   | 1біт| 1 біт| 3 біти | 7 бітів  |
* Рівень заряду батареї (біти 6–0, offset = 0, width = 7) — діапазон значень становить 0–100%.
* Режим роботи (біти 9–7, offset = 7, width = 3) — перелік enum class DeviceMode зі значеннями від 0 до 5 (*Off, Standby, Active, Sleep, Charging, Diagnostic*).
* Wi-Fi увімкнено (біт 10, offset = 10, width = 1) — однобітний прапорець (0 або 1).
* Bluetooth увімкнено (біт 11, offset = 11, width = 1) — однобітний прапорець (0 або 1).
* Код помилки (біти 19–12, offset = 12, width = 8) — числовий код від 0 до 255.
* Температура зі зміщенням (біти 26–20, offset = 20, width = 7) — у бітах зберігається число від 0 до 120. Фактична температура вираховується за формулою stored_value - 40 (діапазон від -40°C до +80°C).
* Потрібне обслуговування (біт 27, offset = 27, width = 1) — однобітний прапорець (0 або 1).
* Резерв (біти 31–28, offset = 28, width = 4) — за умовою варіанта завжди заповнений нулями.

## Використання побітових операцій у коді
Замість стандартних бітових полів структур C++, які працюють нестабільно і залежать від конкретного компілятора, уся логіка пакування реалізована вручну через побітові оператори:

* **AND (&)** — застосовується разом із маскою для ізольованого виділення потрібних бітів під час читання даних (геттери)OR (|)|)** — об'єднує окремі підготовлені та зсунуті біти в одне спільне число під час записуXOR (^)^)** — використовується в методі перемикання Bluetooth (toggle_bluetooth), щоб швидко інвертувати стан прапорця між 0 та 1NOT (~)~)** — у поєднанні з оператором AND повністю очищає старі біти конкретного поля перед тим, як записати туди нове логічне значення (сеттери).
* **Зсуви (<<, >>)** — переміщують значення на потрібну позицію (offset) вліво або вправо всередині 32-бітного числа.
